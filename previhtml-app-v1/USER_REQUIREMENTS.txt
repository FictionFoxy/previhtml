User requirements (as requested):

1) Project conversion
- Convert the existing project into a full React + Vite + Mantine app.
- Single editable text area in the UI (no form inputs). The user edits text in one place only.
- An LLM (OpenRouter) will take that single editable text and decide how to stylize/format it into HTML for the preview.
- The app should not use any HTML form submission; all edits are live and local.

2) OpenRouter integration and settings
- Use "openrouter" as the LLM provider.
- API key is stored in app settings inside the web app and persisted to localStorage.
- Settings UI must live in the app and allow the user to paste/save the OpenRouter API key and toggle features.
- The app should read the API key from localStorage for requests (no server required by default).

3) Autosave and persistence
- Autosave the user's editable text and app settings to localStorage every 5 seconds.
- Additionally, provide a local script (separate from the web app) that, when run, will commit the project files to the local git repository after each autosave. This script will be optional and run manually by the user.
- The web app should also keep an in-app changelog/log viewer showing autosave events and errors.

4) Collapsible log viewer
- Add a collapsible, persistent log viewer pane in the UI that records events (autosaves, OpenRouter requests/responses status, errors).
- The collapsed/expanded state should persist in localStorage.

5) Copy/sync to Downloads on SD card
- The user requested the project be copied to the SD card Downloads location for testing.
- Behavior described by user: "the symlink takes the project dir and copies it to the downloads on sd." Clarification: symlink and copy are different; user wants the project mirrored/copied to the Android SD card Downloads folder.
- Implementation plan: add a shell script (scripts/copy_to_sd.sh) that copies the entire project directory to the provided SD Downloads path. Also include instructions on how to create a symlink locally if desired.
- The app itself doesn't create OS-level symlinks; the provided script will perform the copy/mirror operation and can optionally create a symlink.

6) UI and preview
- Use Mantine components for layout, editor, settings modal, and collapsible log viewer.
- The preview pane shows the HTML output generated by OpenRouter (or a local fallback formatter if no API key is present).
- Include a "Copy" button to copy the generated HTML (rich) to the clipboard.

7) Security & UX
- Do not store API keys on any remote server; keep them in localStorage only.
- Provide clear indicators in the UI when using the live OpenRouter service vs local fallback (offline mode).

8) Developer scripts & extras
- Add package.json scripts for dev/build/preview and a node script to run the optional git-commit-on-save job (scripts/autocommit.js).
- Provide README with instructions: how to install deps, run dev server, configure OpenRouter key in app settings, run the copy-to-SD script, and run the autocommit script.

Notes/Assumptions
- The web app will make requests directly to OpenRouter from the client; some OpenRouter providers require CORS or a proxy. If CORS prevents client-side calls, the README will note running a simple proxy or storing the key in a local server.
- The copy script will request the SD path from the user at runtime or accept a configured path variable.

End of user-specified requirements.
